# Политика безопасности

## Сообщение об уязвимости
Не публикуй эксплуатационные детали неизвестной уязвимости в открытом issue. Если в репозитории доступна функция **Private vulnerability reporting**, используй её на вкладке **Security**. Если она недоступна, сначала открой issue без эксплойта и попроси приватный канал связи.

Укажи затронутую версию, условия воспроизведения, ожидаемое и фактическое поведение и возможное влияние. Не прикладывай личные резервные копии, токены, пароли или журналы с приватными путями.

## Ограничения
- Программа работает с файловой системой с правами текущего пользователя и может создавать, заменять и восстанавливать файлы в выбранных каталогах.
- Установщик не подписан Authenticode; SHA-256 помогает выявить повреждение загрузки, но не является цифровой подписью издателя.
- Программа не создаёт образ Windows и не гарантирует копирование заблокированных файлов.
- Проверка CI не заменяет тест восстановления на реальной Windows-системе.
