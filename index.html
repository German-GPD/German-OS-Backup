СДЕЛАНО ДЛЯ ПОВСЕДНЕВНОГО ИСПОЛЬЗОВАНИЯ

Просто работает.
Не отвлекает.

Понятная панель показывает состояние копии, объём сохранённых данных, ошибки и скорость. Для выбранных папок можно отдельно включить динамическое обновление при изменениях.

01

Понятная настройка

Добавь папки-источники, выбери каталог назначения и проверь пути перед запуском. Настройки можно изменить позже.

02

Копирование под твоим контролем

Сканирование и копирование запускаются вручную. Приложение показывает скорость, число файлов и ошибки; можно остановить текущую операцию и выбрать режим нагрузки.

03

Удалил? Копия остаётся

Если оригинал исчезает, программа не удаляет сохранённую копию автоматически. Это помогает пережить случайное удаление.

04

Управление без лишнего

Единый интерфейс приложения работает на C# и WebView2; файловые операции выполняет Rust-движок.

05

Проверка целостности

Глубокая проверка сравнивает файлы по SHA-256 и показывает отсутствующие или отличающиеся копии.

06

Восстановление без перезаписи

Можно вернуть отсутствующие файлы из выбранного бэкапа. Уже существующие файлы не перезаписываются.

07

Обновление в пару нажатий

Версия видна на сайте и в приложении. Проверяй новые версии на официальной странице релизов.

ЧТО ПОПАДАЕТ В КОПИЮ

Выбираешь сам. Один диск.

01
Users

Выбери весь профиль или только нужное: документы, рабочий стол, AppData и другие доступные папки.

02

Общие данные приложений и пользовательские каталоги. Можно добавить любую доступную папку.

Источники настраиваются кнопкой «Источники…» прямо в приложении. Сохраняются файлы и структура папок; это не полный образ диска и не автоматическое восстановление Windows.

ПЕРЕД УСТАНОВКОЙ

Коротко о важном.

Какая версия сейчас актуальна?

Версия сайта берётся из version.json. В релизе будет один установщик единого приложения. Если ссылки временно не работают, проверь статус сборки в GitHub Actions.

Как обновить программу?

Проверяй новые версии через GitHub Releases. Настройки и резервные копии хранятся отдельно от установщика.

Программа бесплатная?

Да. Проект открыт под лицензией MIT. Нет рекламы, аккаунта, телеметрии и сетевой синхронизации. Подключение к GitHub происходит только при ручной проверке обновлений.

Она удаляет резервные копии?

Нет, удаление оригинального файла не удаляет его копию. Поэтому со временем резервная папка может занимать больше места.

Скопируется абсолютно всё?

Нет гарантии. Файлы, занятые другими программами или закрытые правами доступа, могут пропускаться; ошибки записываются в журнал. Установщик запрашивает административные права для установки, но доступ к файлам всё равно зависит от разрешений Windows.

Как проверить, что копия не повреждена?

В приложении запусти «Глубокая проверка (SHA-256)». Проверка читает исходные и резервные файлы, поэтому для большой библиотеки может занять время.

Как вернуть файлы после переустановки Windows?

Открой функцию «Восстановить», укажи прежнюю папку бэкапа и папку назначения. Восстановятся только отсутствующие файлы; существующие не перезаписываются.

Можно ли восстановить Windows целиком?

Нет. Это копирование отдельных файлов и папок, а не образ системы, копия загрузчика или полноценная система восстановления.

Куда обращаться, если что-то не работает?

Открой журнал через меню значка в трее, затем создай issue в GitHub и приложи подходящий фрагмент журнала. Перед публикацией удали личные пути и приватные данные.

!
Резервная копия — не магия.

Первое копирование может занять часы и потребовать много места. Для важных файлов держи ещё одну копию на отдельном физическом носителе и периодически проверяй, что файлы действительно открываются.
