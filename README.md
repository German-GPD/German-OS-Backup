# German OS Backup

**Фоновая резервная копия Windows без рекламы, аккаунтов и телеметрии.**

[Скачать для Windows x64](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-win-x64.zip) · [Все релизы](https://github.com/German-GPD/German-OS-Backup/releases) · [Сайт проекта](https://german-gpd.github.io/German-OS-Backup/)

> Прямая ссылка на ZIP заработает после публикации первого релиза. До этого можно скачать сборку из раздела **Actions → последний успешный запуск → Artifacts**.

## Что делает

- При первом запуске предлагает выбрать папку резервной копии на другом диске.
- Копирует существующие папки `C:\Users`, `C:\ProgramData` и `C:\XboxGames`.
- Отслеживает изменения и повторно сканирует источники каждые 15 минут.
- **Не удаляет копии**, если исходные файлы или папки исчезли.
- Устанавливает пользовательскую копию в `%LOCALAPPDATA%\Programs\GermanOSBackup\` и запускается с Windows.
- Работает с низким приоритетом процесса и находится в системном трее.
- Позволяет вручную запустить проверку, открыть папку копий и журнал, отключить автозапуск или выйти.

## Installation

1. Скачай ZIP по ссылке **[GermanOSBackup-win-x64.zip](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-win-x64.zip)** и распакуй его.
2. Запусти `GermanOSBackup.exe`. При первом запуске Windows может показать предупреждение SmartScreen: приложение пока не подписано цифровым сертификатом.
3. Выбери папку на другом диске, например `D:\OS-Backup` или `F:\OS`. Системный диск для назначения запрещён.
4. Программа скопирует себя в папку пользователя, зарегистрирует запуск с Windows и начнёт резервное копирование. Значок щита появится в системном трее.

Для остановки нажми правой кнопкой по значку в трее → **Выход**. Для отключения запуска с Windows выбери соответствующий пункт меню. Настройки и журнал находятся в `%LOCALAPPDATA%\GermanOSBackup\`.

## Сборка из исходников

Нужны Windows и .NET 10 SDK:

```powershell
dotnet publish .\src\GermanOSBackup\GermanOSBackup.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

GitHub Actions выполняет сборку автоматически при push в `main`. ZIP появляется в **Actions → Artifacts**. При создании тега `vX.Y.Z` workflow публикует архив в GitHub Releases.

## Важные ограничения

- Это файловая резервная копия, а не образ Windows и не средство восстановления загрузчика.
- Копирование файлов, к которым нет доступа или которые заняты приложением, может завершиться ошибкой; смотри журнал. Программа не получает права администратора автоматически.
- Файлы, которые постоянно изменяются (например, активные сохранения), могут попасть в копию в промежуточном состоянии.
- Первое копирование может занять часы и много места. Нужны достаточный объём диска и права чтения.
- При удалении оригинала копия сохраняется намеренно. Это помогает от случайного удаления, но резервная папка будет постепенно занимать больше места.
- Для важных данных рекомендуется ещё одна копия на отдельном физическом носителе.

## Конфиденциальность

Приложение не содержит аналитики, рекламных SDK, аккаунтов или сетевой синхронизации. Файлы копируются локально на выбранный диск. Исходный код и workflow открыты для проверки.
