# German OS Backup · Rust Edition

> **Windows 10/11 · x64 · Native Rust UI**  
> [Сайт проекта](https://german-gpd.github.io/German-OS-Backup/) · [Скачать Rust Edition](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-Rust-Setup-x64.exe) · [Все релизы](https://github.com/German-GPD/German-OS-Backup/releases)

Нативное приложение для локального резервного копирования выбранных папок. Без рекламы, аккаунтов, телеметрии и WebView2.

## Возможности

- Ручное копирование выбранных папок на указанный диск.
- Динамическое автообновление включается отдельно у каждой папки; новые и изменённые файлы копируются автоматически, удаление оригинала не удаляет резервную копию.
- Повторное копирование новых и изменённых файлов; время изменения источника сохраняется, чтобы неизменённые файлы не копировались повторно.
- Защита от пересечения папки назначения с источниками, вложенных источников и одинаковых имён корневых папок.
- Счётчики, скорость, ошибки и мониторинг CPU/RAM.
- Проверка целостности по SHA-256.
- Восстановление отсутствующих файлов без перезаписи существующих.
- Создание ZIP-архива из текущей папки резервной копии.
- Локальные настройки и журнал.

## Скачать и запустить

1. Скачай **GermanOSBackup-Rust-Setup-x64.exe** из раздела релизов.
2. Установи приложение.
3. Выбери источники и папку назначения на другом диске.
4. Проверь пути и нажми **«Начать копирование»**.

## Сборка из исходников

Нужен стабильный Rust toolchain и Windows SDK для MSVC.

```powershell
cargo build --release --target x86_64-pc-windows-msvc
```

Исполняемый файл: `GermanOSBackup-Rust.exe`. Установщик собирается через Inno Setup 6 и `installer/GermanOSBackup-Rust.iss`.

## Важные ограничения

Это файловая копия, а не образ Windows. Заблокированные или недоступные файлы могут быть пропущены; смотри журнал. Восстановление не перезаписывает существующие файлы. Для важных данных держи ещё одну копию на отдельном физическом носителе.
