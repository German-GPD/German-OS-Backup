# German OS Backup

**Локальное резервное копирование файлов Windows. Без рекламы, аккаунтов и телеметрии.**

[**↓ Скачать для Windows (ZIP, x64)**](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-win-x64.zip) · [Сайт проекта](https://german-gpd.github.io/German-OS-Backup/) · [Исходный код](https://github.com/German-GPD/German-OS-Backup)

> **Важно:** это файловая копия выбранных папок, а не образ Windows и не средство полного восстановления системы.

## Возможности

- Первый запуск предлагает выбрать папку резервной копии на другом диске.
- Копирует доступные файлы из C:\Users, C:\ProgramData и C:\XboxGames (если папки существуют).
- Отслеживает изменения и выполняет повторное сканирование каждые 15 минут.
- Не удаляет сохранённую копию, когда оригинальный файл или папка исчезает.
- Устанавливает пользовательскую копию в %LOCALAPPDATA%\Programs\GermanOSBackup\.
- Может запускаться вместе с Windows; работает с низким приоритетом и находится в системном трее.
- Через меню трея можно запустить проверку, открыть папку копий или журнал, изменить автозапуск и выйти.

## Установка

1. Нажми **«Скачать для Windows»** на [сайте проекта](https://german-gpd.github.io/German-OS-Backup/) или используй [прямую ссылку на ZIP](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-win-x64.zip).
2. Распакуй архив и запусти GermanOSBackup.exe.
3. При первом запуске выбери папку на другом физическом диске/разделе, например D:\OS-Backup или F:\OS. Для назначения системный диск не подходит.
4. Программа установит свою копию в профиль пользователя и начнёт копирование. Значок появится в системном трее.

Windows SmartScreen может предупреждать о неизвестном издателе: приложение пока не подписано цифровым сертификатом. Запускай его только если скачал с официальной страницы этого репозитория и доверяешь исходному коду.

**Управление:** нажми правой кнопкой по значку щита в системном трее. Там доступны ручная проверка, папка резервной копии, журнал, настройки автозапуска и выход.

Настройки и журнал хранятся в %LOCALAPPDATA%\GermanOSBackup\.

## Какие данные копируются

| Источник | Что это |
| --- | --- |
| C:\Users | Профили пользователей и доступные пользовательские файлы |
| C:\ProgramData | Общие данные приложений |
| C:\XboxGames | Игры в стандартной папке Xbox |

Копируются файлы и структура каталогов. Программа не удаляет резервные файлы автоматически. При обновлении файла в источнике его копия обновляется на месте; это **не версионная история**, поэтому предыдущие версии изменённого файла не сохраняются.

## Ограничения и безопасность

- Это не образ диска, не резервная копия загрузчика и не инструмент восстановления Windows целиком.
- Приложение не запрашивает права администратора автоматически. Недоступные, занятые или защищённые файлы могут быть пропущены; подробности смотри в журнале.
- Файлы, изменяющиеся во время копирования, могут попасть в промежуточном состоянии.
- Первое копирование может занять часы и много места.
- Копии намеренно не удаляются при удалении оригиналов, поэтому резервная папка постепенно может расти.
- Если исходник и копия находятся на одном физическом диске, отказ этого диска может уничтожить обе. Для важных данных храни ещё одну копию на отдельном носителе и проверяй, что файлы открываются.

## Конфиденциальность

Приложение не содержит аналитики, рекламных SDK, учётных записей или сетевой синхронизации. Файлы копируются локально в выбранную папку.

## Сборка из исходников

Нужны Windows и .NET 10 SDK:

    dotnet publish .\src\GermanOSBackup\GermanOSBackup.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish

GitHub Actions автоматически собирает приложение для Windows x64 при изменениях в main. ZIP публикуется в стабильный GitHub Release.
