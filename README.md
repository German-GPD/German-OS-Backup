# German OS Backup

**Резервное копирование Windows с desktop-интерфейсом, статистикой и автозапуском.**

[**↓ Скачать установщик Windows x64**](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-Setup-x64.exe) · [Сайт проекта](https://german-gpd.github.io/German-OS-Backup/) · [Исходный код](https://github.com/German-GPD/German-OS-Backup)

## Что умеет

- Устанавливается через обычный Windows installer в `C:\Program Files\German OS Backup`.
- Добавляет запуск в фоне вместе с Windows и значок в системном трее.
- При первом запуске предупреждает о нагрузке, предлагает выбрать диск для копии и начинает первичное сканирование с повышенным приоритетом и параллельным копированием. После первого запуска работает в фоне с пониженным приоритетом.
- Показывает статус, объём скопированных данных, количество файлов, ошибки и текущую скорость.
- Позволяет выбрать источники в дереве папок и добавить произвольные каталоги, включая вложенные папки профиля, `AppData`, `Program Files` и игровые библиотеки.
- Проверяет выбранные пути и запрещает назначать папку копии внутри источника или наоборот.
- Обновляет наблюдение за источниками сразу после сохранения — перезапуск не требуется.
- Отслеживает изменения и выполняет повторную полную проверку каждые 15 минут; также можно запустить её вручную.
- Не удаляет сохранённые копии при удалении оригиналов.
- Позволяет вручную запустить глубокую проверку копии по SHA-256.
- Восстанавливает отсутствующие файлы из выбранной копии, не перезаписывая уже существующие файлы; папки-ссылки не обходятся.
- Работает локально: без рекламы, аккаунтов, телеметрии и облачной синхронизации.

## Установка

1. Скачай [GermanOSBackup-Setup-x64.exe](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-Setup-x64.exe).
2. Запусти установщик. Для установки в Program Files потребуется подтверждение Windows UAC.
3. После установки приложение запустится автоматически. При первом запуске выбери папку на другом диске, например `D:\OS-Backup`.
4. Прочитай предупреждение о первом копировании и нажми «Начать полное копирование». Программа начнёт работать и останется доступна из системного трея.

Автозапуск включён по умолчанию. Закрытие окна прячет приложение в трей, а пункт «Выход» в меню трея полностью останавливает его до следующего запуска Windows.

## Проверка и восстановление

- Для проверки наличия и целостности файлов открой меню значка в трее и выбери «Глубокая проверка (SHA-256)». Сравнение читает оригиналы и резервные файлы, поэтому может занять заметное время.
- Чтобы вернуть данные, выбери в меню трея «Восстановить из копии…», укажи корень резервной папки и папку назначения. Будут созданы только отсутствующие файлы; существующие не перезаписываются.
- Восстановление не возвращает Windows, программы или загрузчик целиком. Перед восстановлением важных данных убедись, что выбраны правильные папки.
- Если Windows переустановлена или настройки приложения сброшены, запусти приложение и вручную укажи прежнюю папку резервной копии в окне восстановления. Настройки приложения находятся отдельно в `%LOCALAPPDATA%\\GermanOSBackup\\` и могут не сохраниться после очистки профиля.

## Выбор источников

По умолчанию доступны `C:\Users`, `C:\ProgramData` и `C:\XboxGames`. В главном окне нажми «Источники…», чтобы выбрать конкретные папки или добавить произвольный каталог через «Добавить папку…». Например, можно выбрать только `AppData\Roaming`, папку документов или библиотеку игр, не копируя весь профиль пользователя.

Доступ к защищённым каталогам зависит от разрешений Windows. Назначение резервной копии должно быть отдельной папкой на другом диске и не может пересекаться с выбранными источниками.

## Важно знать

- Это файловая копия, а не образ Windows и не полноценное восстановление системы.
- Первое копирование может занять часы и активно использовать диск. Скорость зависит от исходного накопителя, назначения, количества мелких файлов и прав доступа.
- Приложение не повышает собственные права автоматически. Некоторые системные файлы, файлы открытых приложений или защищённые данные могут не скопироваться. Смотри журнал ошибок в интерфейсе.
- Если файл изменился, его копия обновляется на месте. Предыдущие версии изменённого файла не сохраняются.
- При удалении оригинала копия остаётся; поэтому со временем резервная папка может увеличиваться.
- Назначение на другой раздел того же физического диска не защищает от отказа самого диска. Для важных данных используй дополнительную копию на отдельном физическом носителе.
- Программа не подписана цифровым сертификатом, поэтому Windows SmartScreen может показывать предупреждение об неизвестном издателе. Загружай установщик только из этого репозитория.

## Конфиденциальность

Файлы копируются в выбранную локальную папку. Приложение не использует рекламу, аналитические SDK, учётные записи или облачную синхронизацию.

Настройки и журнал хранятся в `%LOCALAPPDATA%\GermanOSBackup\`.

## Сборка из исходников

Нужны Windows, .NET 10 SDK и Inno Setup 6.

```powershell
dotnet publish .\src\GermanOSBackup\GermanOSBackup.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
iscc .\installer\GermanOSBackup.iss
```

GitHub Actions автоматически собирает установщик для Windows x64 и публикует его в GitHub Releases.
