# German OS Backup C# Edition

[↓ Скачать C# Edition для Windows x64](https://github.com/German-GPD/German-OS-Backup/releases/latest/download/GermanOSBackup-CS-Setup-x64.exe)

Это ветка cs: классическая версия на C# / .NET 10 с Windows Forms и WebView2.

- Настройки и резервные копии хранятся локально.
- Есть системный трей, журнал, мониторинг CPU/RAM, выбор источников и папки назначения.
- Поддерживаются глубокая проверка SHA-256, восстановление отсутствующих файлов и ручная проверка обновлений.
- Без рекламы, аккаунтов и телеметрии.

Основная Rust Edition: https://github.com/German-GPD/German-OS-Backup/tree/main
