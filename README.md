# German OS Backup

**Текущая версия:** `1.4.1` · Единый установщик для Windows x64

> **Windows 10/11 · x64 · один установщик · C# + WebView2 · Rust Engine · v1.4.1**

[Сайт проекта](https://german-gpd.github.io/German-OS-Backup/) · [Релизы](https://github.com/German-GPD/German-OS-Backup/releases) · [Сообщить об ошибке](https://github.com/German-GPD/German-OS-Backup/issues)

Локальная резервная копия файлов без рекламы, аккаунтов и телеметрии. Приложение использует **C# + WebView2 для интерфейса и нативный Rust-модуль для атомарного копирования небольших файлов** (например, игровых сохранений) в режимах «Баланс» и «Максимальная скорость». Большие файлы и режим экономии используют управляемое асинхронное копирование, чтобы сохранять прогресс и возможность остановки.

## Единая версия

- **Интерфейс:** C# / .NET 10 + Microsoft WebView2.
- **Движок:** Rust `cdylib` вызывается из C# через стабильный нативный интерфейс; для режима экономии и разработки предусмотрен управляемый путь копирования.
- **Дизайн:** чёрная тема с зелёными акцентами, полупрозрачные поверхности Windows Mica и острые углы.
- **Платформа:** Windows 10/11 x64.
- **Хранение:** локально; без рекламы, аккаунтов и телеметрии.

## Возможности

- Выбор папок-источников и отдельного каталога назначения. По умолчанию предлагаются «Документы», AppData и сохранённые игры; AppData Local, ProgramData и XboxGames можно добавить отдельно.
- Ручное копирование и динамическое обновление выбранных папок.
- Удаление оригинала не удаляет сохранённую копию автоматически.
- Прогресс, скорость, счётчики, ошибки и журнал.
- Проверка целостности файлов по SHA-256.
- Восстановление отсутствующих файлов без перезаписи существующих.
- Создание ZIP-архива.
- Локальные настройки и запуск вместе с Windows по желанию.

## Установка

Скачай **единственный установщик German OS Backup** со страницы [GitHub Releases](https://github.com/German-GPD/German-OS-Backup/releases/latest). После первого запуска выбери папки, которые нужно сохранять, и папку назначения на другом диске.

Для важных данных держи дополнительную копию на отдельном физическом носителе. Это файловое резервное копирование, а не образ Windows: программа не сохраняет загрузчик и не обещает восстановление операционной системы целиком. Заблокированные или недоступные текущему пользователю файлы могут не скопироваться — проверяй журнал.

## Разработка

Основная рабочая ветка — `main`. CI собирает нативный Rust-модуль, упаковывает его вместе с приложением и выпускает один установщик. Старые ветки ещё не удалены.

Для сборки C#-приложения нужны .NET 10 SDK и Inno Setup 6. Для Rust-движка — стабильный Rust toolchain и цель `x86_64-pc-windows-msvc`. Сборка релиза должна публиковать один установщик только после успешного прохождения проверок.
